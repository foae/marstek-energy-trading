# Security Policy

## Reporting

Please report security vulnerabilities and battery-control safety issues through GitHub's private vulnerability reporting for this repository. Do not open a public issue containing credentials, private network details, household telemetry, or a procedure that could cause unsafe battery operation.

Include the affected commit, configuration, hardware/firmware versions, expected behavior, observed behavior, and a minimal reproduction when it is safe to provide one. Never reproduce a suspected issue on an unattended battery.

## Scope

Security support covers the current `main` branch. This project is experimental software for a specific local hardware setup, not a safety-certified energy management system. See the README's security and limitations sections before operating it.
